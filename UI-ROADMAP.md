# RuneAmp 0.4.0 — обновление веб-интерфейса

Цель: современная музыкальная оболочка, сохраняя существующий ретро-плеер, скины, аудиотракт и данные. Версия 0.4.0 подготовлена по результатам финальной проверки.

- [x] Дизайн-система: отдельный service.css, локальные SVG-иконки, тёмная/светлая палитры, базовая иерархия кнопок.
- [x] Навигация: постоянная боковая панель на ПК, компактная прокручиваемая навигация на мобильном, отдельные маршруты радио, библиотеки, избранного и недавнего.
- [x] Единая кнопка «Загрузить»: один множественный выбор и существующий drag-and-drop; ZIP (без учёта регистра расширения) направляется на импорт, прочие файлы — на обычную загрузку. Смешанный выбор обрабатывается последовательно в исходно выбранной папке. Архивы RAR/7z пока не поддерживаются.
- [x] Панели массовых действий появляются только при выделении.
- [x] Первое оформление главной и радиостанций: цветовые категории и локальная графика.
- [x] Библиотека: раскрываемое дерево папок с порционной подгрузкой узлов, двухпанельная раскладка, поиск, фильтр форматов, сортировка, сворачиваемые каталоги и виртуальный список. Браузерная проверка на 100 000 треков.
- [x] Плейлисты: карточки с автоматически формируемыми локальными обложками, запоминаемый компактный список, отдельный экран с постоянной ссылкой и поиск внутри. Проверены разные области видимости, история, перезагрузка и виртуализация на 100 000 треков.
- [x] Управление: виртуализированный файловый менеджер с колонками и контекстными действиями, меню обслуживания, единый измеряемый прогресс загрузки треков и ZIP, компактный редактор плейлистов, фильтрация скинов и выделение скина по умолчанию. Проверено в Chrome на тестовом API.
- [x] Мобильная адаптация, светлая и тёмная темы, визуальная проверка на реальных данных (7156 треков); Chrome и Firefox, ширины 320/390/1440. Проверка админки через изолированный тестовый API.
- [x] Регрессионные проверки очередей, смешанной загрузки, скинов, навигации и API на 100 000 треков в Chrome/Firefox; модульные тесты Go и TypeScript. Физическое воспроизведение звука на устройстве пользователя не проверялось.
- [x] Версия поднята до 0.4.0. Публикация тега и Docker-образа через GitHub Actions. Боевой контейнер не обновляется автоматически.

## Ограничения
Не менять внешность и механику самого плеера/мини-плеера, WASM, эквалайзер, визуализаторы, Shuffle и очередь. Не вводить внешние CDN или обязательные онлайн-зависимости. Сохранять виртуализацию больших коллекций и существующие данные.
