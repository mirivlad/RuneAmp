# Темы музыкального сервиса RuneAmp

Темы сервиса не являются Winamp-скинами. Скины управляют внешним видом плеера; темы — публичной оболочкой музыкального каталога. Административный раздел всегда использует независимое базовое оформление. Структура дерева каталогов, очереди, виртуализация и аудиодекодеры не меняются.

## Установка и восстановление
1. Управление → Темы сервиса → Загрузить ZIP.
2. После проверки архив появится в списке. Загрузка не активирует тему автоматически.
3. Нажмите «Применить». Тема используется для всех слушателей при открытии/обновлении страницы; индивидуальный выбор светлого/тёмного режима сохраняется.
4. Для восстановления откройте `/admin?tab=themes` и нажмите «Восстановить заводскую тему». Административный раздел не загружает пользовательское оформление даже при неисправности темы. Удаление активной темы также возвращает заводскую.
5. Для диагностики можно открыть `/?safe-theme=1` — эта страница использует нейтральную базовую оболочку без активной темы, не меняя глобальные настройки.

## Формат ZIP v1
В корне архива должен находиться `theme.json`. Дополнительно допускаются только упомянутые в манифесте PNG/JPEG. Нет вложенных папок, исполняемого кода, HTML, произвольного CSS, SVG, внешних URL или сетевых шрифтов.

Пример полного манифеста (Industrial Music Archive):
```json
{
  "version": 1,
  "name": "Industrial Music Archive",
  "dark": {
    "bg": "#191B19", "panel": "#252824", "line": "#4C5148",
    "text": "#F0EADB", "muted": "#B8BCAD", "accent": "#F4BD66",
    "primary": "#E5A544", "hover": "#343A31", "buttonText": "#221B10",
    "heroA": "#30352C", "heroB": "#191B19",
    "personal": "#D6AA69", "zx": "#B3D177", "ts": "#F096A5",
    "tracker": "#78C5B6", "audio": "#E6AD70"
  },
  "light": {
    "bg": "#E8E4D8", "panel": "#FAF6E9", "line": "#B9B5A6",
    "text": "#272D28", "muted": "#555E51", "accent": "#88501C",
    "primary": "#A55918", "hover": "#DDD8CA", "buttonText": "#FFF8ED",
    "heroA": "#30352C", "heroB": "#191B19",
    "personal": "#D6AA69", "zx": "#B3D177", "ts": "#F096A5",
    "tracker": "#78C5B6", "audio": "#E6AD70"
  },
  "radius": 4,
  "typography": "mono",
  "artwork": "industrial"
}
```

Все цвета обязательны и задаются шестизначным HEX. `radius` — 0–16 пикселей, `typography` — system, mono или serif (заголовки), `artwork` — industrial, geometry или records. Для собственной графики добавьте в манифест, например, `"images": {"hero": "hero.png", "zx": "zx.jpg", "cover": "cover.png"}` и соответствующие файлы в корень архива. Допустимые ключи: hero, personal, zx, ts, tracker, audio, cover. Обложка cover — общий графический фон автоматически создаваемых обложек.

Ограничения: 32 загруженные темы, 4 МиБ на архив/распакованные данные, до 2 МиБ на отдельный файл, PNG/JPEG до 2048×2048. Манифест до 16 КиБ. Архивы и активная тема хранятся в существующей SQLite-базе в /data, вместе с остальными настройками. API изменения доступен только администратору с защитой от CSRF.

Формат v1 намеренно не предоставляет произвольную замену HTML или CSS: тема не должна скрывать управление, подменять формы входа или запускать код. Это контракт оформления, а не расширение логики приложения.
